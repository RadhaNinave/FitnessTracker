# Health And Fitness Tracker

React + Vite practice project matching the supplied reference states.

## Initial state
The app starts with an empty localStorage dataset. The first render shows:
- Update Today's Data card
- + Add data button
- No data available
- Recent Health Statistics / No Progress to show
- Overall Data section

## Features
- Add health data
- Edit and delete records
- localStorage persistence
- Weekly health trends bar chart
- Overall intake vs burned pie chart
- Responsive layout
- Empty state matching the supplied reference

## Run
```bash
npm install
npm run dev
```

To reset the app to the empty state, clear `health-fitness-tracker-data` from browser localStorage.
